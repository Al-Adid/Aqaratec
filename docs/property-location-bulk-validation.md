# خمسة أقسام للعقار وتعبئة مجموعة وحدات

## النتيجة

القسم 1 يعرض رقم السند ورقم المخطط العقاري ورقم العقار والكهرباء. القسم 4 مخصص للموقع الوصفي ورقم المنطقة والشارع والمبنى ورابط الموقع؛ تبقى الأرقام نصوصًا تحفظ الأصفار والأرقام العربية. القسم 5 يدعم صور العقار ومخططات/خرائط متعددة وفيديو محلي ورابط فيديو اختياري. الروابط تُعرض للنقر اليدوي ولا تُجلب تلقائيًا.

تظهر قيمة الإيجار الشهري الحالي عند تصريح مؤجر، وتُحفظ بالوحدة الصغرى في تصريح التأجير المستقل. إذا وُجد عقد مسجل فالمبلغ ومعلومات العقد للقراءة فقط ومن مصدر العقد وبعملته. لا يتحول سعر البيع أو الإيجار المطلوب إلى تحصيل، ولا ينشئ التصريح عقدًا أو استحقاقًا أو قيدًا.

من «إكمال معلومات الوحدات» يمكن فتح التعبئة الجماعية، وتحديد بعض الوحدات أو الكل، واختيار الحقول المشتركة ومعاينتها قبل التطبيق الصريح. لا تُعمم الأسماء أو الرموز أو المعرفات، ولا يُمسح حقل إلا بخيار مسح صريح. التطبيق انتقال واحد دائم، كله أو لا شيء، مع حراسة الدور والنطاق والتعارض والسعة. فشل التخزين يبقي المدخلات دون رسالة نجاح، وتبقى المسودات غير المطبقة محفوظة في الجلسة.

## الأدلة

- pnpm check ناجح.
- 82 اختبارًا متأثرًا في ثمانية ملفات ناجحًا، تشمل الموقع، والمرفقات، والتعبئة، ومعالج 36 وحدة، وصفحة العقار، والإيجار الحالي.
- الفحص العام قبل إغلاق ملاحظتي التوافق والعدد: 111 ملفًا، و708 اختبارات ناجحة واختبار واحد متخطى؛ البناء ناجح.
- بعد إغلاق الملاحظتين: 21 اختبارًا للمرفقات والغلاف ناجحًا في ثلاثة ملفات، وفحص TypeScript ناجح. دليل البناء النهائي محفوظ في سجل final-build.log خارج المشروع.
- مراجعة مستقلة محدودة للقراءة فقط في property-location-bulk-readonly-review.md، مع ملحق إغلاق العائق المثبت بالأدلة. لم تُكتب بيانات إلى قاعدة الإنتاج.

## الحدود

الملفات محلية في IndexedDB لهذا المتصفح ومساحة العمل فقط. لا تحتوي لقطة JSON أو الحفظ السحابي على Bytes الصور أو المخططات أو الفيديو. الحد الكلي 20 صورة و10 مخططات بما فيها المراجع القديمة، وصورة حتى 5 MiB ومخطط حتى 10 MiB وفيديو MP4 أو WebM حتى 50 MiB. يظل بيان المرفقات محدودًا إلى 1024 حرفًا، وقد يتطلب تقليل المراجع الطويلة ضمن هذا الحد دون اقتطاع تلقائي. رابط الفيديو ليس رفعًا إلى استضافة فيديو عامة.

المكتبة الحالية للموقع اسمها newproperty-location.ts، وتستخدمها الشاشة والمدقق والاختبارات. لا يوجد تغيير لواجهات البنك أو البريد أو العقود أو الماليات. حفظ المصدر منفصل عن النشر، والنشر التلقائي متوقف؛ لا تمثل هذه التوسعة تحديثًا عامًا قبل موافقة جديدة.
