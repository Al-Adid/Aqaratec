# مرفقات العقار بأسلوب معرض الوحدات — 27 أكتوبر 2026

## النتيجة

صور العقار، المخططات والخرائط، وفيديو العقار أصبحت ثلاث بطاقات منظمة داخل القسم 5 في إضافة/تعديل العقار، وبنفس الأسلوب في عرض مرفقاته المحفوظة. لكل بطاقة أيقونة وعنوان وزر إضافة أخضر واضح وعدّاد وحدود الصيغ والحجم؛ الصور والمخططات تدعم اختيار مجموعة والفيديو ملفًا واحدًا. ملف PDF له بطاقة ومعاينة تُفتح يدويًا، وللفيديو مشغل محلي ورابط اختياري داخل بطاقته. تُلف أسماء الملفات الطويلة وتظهر حالة بانتظار الحفظ أو ملف محفوظ محليًا، مع أدوات إلغاء/إزالة/تنزيل واضحة. لا تغيير في معرض الوحدات.

يُعيد المكونان استخدام معاينة مشتركة صغيرة وتنسيقًا معزولًا في PropertyMediaGalleryParts.tsx وPropertyMediaGallery.css. لم تتغير مخططات البيانات أو IndexedDB أو prepare/commit/rollback أو قواعد الصلاحيات أو أي عقد أو ذمة أو ماليات. المرفقات تبقى محلية لهذا المتصفح والأصل ومساحة العمل، ولا تُرسل سحابيًا أو مع JSON. لا تُنشأ صور بديلة لملفات مفقودة.

## أدلة التحقق

نجح TypeScript، وجميع 117 ملف اختبار: 743 ناجحًا و1 متخطى. تتضمن اختبارات محرر المرفقات 13 حالة، بينها ضغط كل زر وإيصاله بمدخل الملف المخفي دون إرسال النموذج، وmultiple/accept، ومنع الإضافة عند التعطيل أو دور المالك، وصورة/PDF/MP4 دون كتابة قبل prepare، وبطاقات القارئ وحالة الملف المفقود. بقيت اختبارات التراجع والسعة وفقد الإذن ناجحة. نجحت كذلك 7 اختبارات تكامل لحفظ صورة العقار والوحدة وإعادة فتحهما والغلاف.

نجح البناء النهائي بعد آخر تعديل CSS وgit diff --check. التحذير الوحيد المتعلق بالبناء هو حجم بعض حزم الواجهة، وهو غير مانع كما في الإصدارات السابقة.

فُتح نموذج تعديل عقار صوري موجود في المعاينة دون حفظ تغييرات. أثبت DOM ظهور الأزرار الثلاثة ومدخلاتها المخفية والتنبيه المحلي. كشفت المعاينة وراثة منع التفاف النص من صف الجدول، فحُصرت المعالجة في property-dialog بتصفير الحد الأدنى للأقسام وعمود grid مرن وعزل white-space. بعد الإصلاح كان عرض form الداخلي وتمريره 515px مقابل 515px، وبطاقات المرفقات 431px مقابل 431px دون تجاوز أفقي. لا يُدعى تنفيذ قياس جهاز iPhone فعلي؛ التنسيق يتضمن قواعد الجوال وRTL وفحص الأسماء الطويلة.

## حدود التسليم

هذا تحديث عرض محفوظ للمعاينة فقط، بلا طلب نشر عام جديد. لم تُفتح بيانات حساب المستخدم أو تُغير صوره أو أعداد وحداته، ولم تُنشأ مداخل اختبار مؤقتة في التطبيق. يفصل التنبيه الواضح معاينة الملفات عن حفظها الفعلي بزر حفظ العقار/التعديل.
