# واجهة اختيار موجز الوسطاء

تشرح هذه الصفحة مسار الواجهة في `client/src/pages/marketing/BrokerMarketingPage.tsx`. هذا المسار محلي وتجريبي بالكامل: لا يستدعي SMTP أو مزود بريد أو شبكة، ولا يغير العقود أو الإشغال أو الذمم أو التحصيل.

## المسار المختصر

1. **اختيار العقارات والإيجار:** تعرض الصفحة كل الأهداف المطابقة للمرشحات. يحدد مربع «تحديد الكل» كل النتائج الظاهرة في المرشح الحالي، وتظهر حالته الجزئية عند اختيار بعض النتائج فقط. السعر الظاهر في كل صف هو `rentDraft[id] ?? amountInput(target.suggestedMonthlyRentMinor)`؛ لذلك يظهر مصدر السعر المقترح قبل اختيار العقار، ولا يستبدل تعديل الموظف أو فراغه المتعمد عند التبديل. يظهر أيضًا مصدر القيمة، مثل إيجار الوحدة أو إيجار العقد النافذ/السابق أو إيجار العقار/الوحدة الافتراضي، مع تاريخ المصدر إن توفر.
2. **اختيار الشركات:** يحدد «تحديد المؤهل» كل شركات الوساطة النشطة والمؤهلة ضمن نتائج البحث/الحالة الظاهرة، ويستثني الموقوفة أو ناقصة بيانات المستلم. الاختيارات ليست مقيدة بحدود الدفعة القديمة 10 أهداف أو 20 وسيطًا؛ يفصلها المحرك لاحقًا إلى دفعات آمنة.
3. **مراجعة الموجز:** عنوان الحملة الافتراضي قابل للتحرير، وكذلك المقدمة. لا يؤدي فتح لقطة تاريخية إلى تغيير هذه المحاولة أو إعادة استخدام اختياراتها.
4. **تجهيز ثم تأكيد:** يستدعي زر التجهيز `saveBrokerCampaignBatches` داخل `commitTransition` واحد لجميع الاختيارات الحالية. تعرض الصفحة كل اللقطات الناتجة وكل المستلمين قبل إتاحة زر **«إرسال الموجز للشركات المختارة — تجريبي»**. يعرض مربع تأكيد أسماء المستلمين والدفعات بوضوح.
5. **محاكاة محلية:** بعد التأكيد تستدعي الصفحة `simulateBrokerCampaignBatches` لجميع معرفات دفعات المحاولة في انتقال واحد. تستخدم المحاولة `requestId` ثابتًا عند النقر المتكرر، ولذلك لا تنتج النقرات المزدوجة دفعات أو نتائج محاكاة إضافية. تعرض النتيجة كل دفعة وكل مستلم بوصف «لم يُرسل بريد».

## اللقطات ومسودات البريد

اللقطات التاريخية قسم قراءة وتنزيل مستقل ولا تحتوي زر تأكيد للمحاولة الجديدة. لكل مستلم يمكن تنزيل مسودة EML، وعندما يسمح طول الرابط، فتح مسودة في تطبيق البريد المحلي عبر `mailto:`. فتح المسودة لا يرسل أي رسالة ولا يسجل نجاحًا؛ يراجع المستخدم المسودة ويرسلها بنفسه من تطبيقه. الإرسال المباشر يتطلب مزود بريد موثقًا وموافقة مستقلة.

## الصلاحيات

دور القراءة فقط يستطيع التنقل ومراجعة اللقطات والتنزيلات، لكنه لا يستطيع تحديد العقارات أو الوسطاء، أو تعديل السعر/الموضوع، أو تجهيز دفعات، أو فتح تأكيد المحاكاة.

## التحقق

يغطي الاختبار المركز `BrokerMarketingPage.test.tsx` ما يلي:

- تحديد الكل بالمرشحات، والحالة الجزئية، وعدم قص الاختيارات إلى 10/20.
- ظهور الإيجار المخزن قبل التحديد وحفظ تعديل الإيجار عبر تبديل الاختيار.
- ظهور المستلمين المختارين فقط في التأكيد ونتيجة المحاكاة، مع منع تكرار النقر من إنشاء نتائج جديدة.
- تعطيل الاختيار والتعديل والتجهيز والتأكيد لدور القراءة فقط مع استمرار عرض اللقطات التاريخية.

شغّل التحقق المركز بالأمر:

```bash
pnpm vitest run client/src/pages/marketing/BrokerMarketingPage.test.tsx
pnpm check
```
