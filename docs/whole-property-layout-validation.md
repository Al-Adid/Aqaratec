# تكوين الوحدة والعقار الكامل والوصف النصي الظاهر

26 أكتوبر 2026 — تحديث المعاينة فقط. طلب النشر السابق نفّذ الإصدار af96b1b ولم يعطِ تفويضًا تلقائيًا لنشر هذا التغيير اللاحق.

## المطلوب والنتيجة

خيارات الاستوديو وغرفة وصالة وغرفتين وصالة و3/4/5 غرف وصالة والتوزيع المخصص ظاهرة الآن في معلومات كل وحدة مادية وفي المرحلة الثانية، حتى لو لم تختَر شقة أو لم تصنّف الوحدة بعد. بجانبها عدد الغرف والصالات والحمامات والمطابخ والتأثيث. اختيار تركيب غرف لا يحول الفيلا أو المكتب أو الوحدة غير المصنفة إلى شقة. ترتيب الفيلا وقواعد الشقة القديمة ما زالا متحققًا منهما؛ الغرف/الصالة تضبط فقط عند اختيار المستخدم نموذجًا قياسيًا، والمخصص يبقي أعداده دون اختلاق ولو طابقت نموذجًا قياسيًا. عدّادات المدخلات بين 0 و20، والأعداد الناقصة تبقى غير مسجلة.

العقار المعروض كاملًا للبيع أو الإيجار أو كلا الهدفين يحتوي قسم «مواصفات العقار الكامل — يتكوّن من» ضمن إضافة/تعديل العقار: نفس النماذج وأعداد الغرف والصالات والحمامات والمطابخ والتأثيث وترتيب الفيلا الاختياري. مواصفاته تحفظ في الأصل نفسه، وتعرض في ملفه وتسترجع عند تعديل بياناته؛ لا تنشئ وحدة مادية إضافية ولا توزع مواصفاته على الوحدات.

حقل «وصف نصي إضافي للعقار» ظاهر دائمًا ضمن البيانات الأساسية وليس داخل تفاصيل قابلة للطي. يبقى مستقلًا عن select «وصف العقار» شقق/فلل/وحدات ترميز وعن قائمة المحتويات/المرافق. التصنيف لم يعد يفرض التقسيم؛ عرض كامل أو تقسيم إلى وحدات اختيار صريح، والتقسيم الصريح يتابع رحلة المرحلة الثانية المعتادة.

## الربط والحفظ

المكون المشترك RoomLayoutFields يعرض الاختيارات والعدادات والتأثيث، والمكتبة room-layout تقرأ وتتحقق من facts دون تخمين العدد أو النوع. UnitProfile.roomLayout عام اختياري مع توافق apartmentLayout القديم للشقق؛ الملفات القديمة لا ترحّل تلقائيًا، وتعرض قيمها من الحقول القديمة عند القراءة. إذا غير المستخدم نوع شقة قديمة صراحة، تحفظ النافذتان تركيب غرفها الحالي في الحقل العام فقط إذا بقي المصدر القديم نفسه الأحدث؛ تعديل نص أو سعر عادي لا يولد ترحيلًا.

PropertyProfile.accommodation ملف صغير مستقل يضم التكوين والأعداد والتأثيث وترتيب الفيلا فقط. لا أسعار أو هويات أو مساحة فيه. مسودة UI سلسلة JSON بمفاتيح وقيم نصية محددة، وتحوّل إلى أعداد/enums متحققة عند الحفظ ضمن حد ملف 1024 حرفًا و32 مفتاح metadata. إرسال المواصفات يعتمد مقارنة اللقطة المفتوحة بالأحدث: إدخال حمام جديد لا يستبدل مطبخًا أحدث غير معدل، والنموذج القياسي الجديد يعدّ اختيارًا صريحًا مركبًا مع غرفه وصالته.

هدف العقار الكامل الداخلي يقرأ مواصفات الأصل والنص الوصفي من العقار، ويعرض رابط تعديل العقار بدل تحرير نسخة مواصفات وحدة ثانية. الصور المحلية IndexedDB وحدودها ورسائلها لم تتغير، ولا نقل صور سحابي جديد ولا خدمة إرسال أو قاعدة بيانات جديدة. المبالغ والمساحات والتأجير والعقود والعلاقات والرموز والذمم والتحصيل منفصلة عن الوصف ولم ينشئ إدخال تركيب غرف أثرًا ماليًا.

## المراجعة والإصلاح المحدد

المراجعة المستقلة المقروءة وجدت تجاوزًا وحيدًا: الملف الخام legacy unitProfile وفيه category=apartment وapartmentLayout=1-living كان يستطيع إنشاء تركيب شقة على الهدف الداخلي للعقار الكامل رغم منع roomLayout الجديد. أغلقت حراسة updateDescribedUnit إسناد توزيع عام أو توزيع شقة قديم إلى هذا الهدف، وثبت الرفض الذري وبقاء الحالة الأصلية كما هي باختبار الانحدار. حفظ الاسم أو عدد غرف تاريخي فقط بلا إنشاء توزيع ثانٍ بقي متاحًا، ولا توسيع إلى خدمات أو نطاق غير مطلوب.
