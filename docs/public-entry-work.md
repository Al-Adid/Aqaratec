# الصفحة العامة والتسجيل وحملات الوسطاء

طلب المستخدم إضافة صفحة رئيسية تعرض خدمات المشروع ومنها التسجيل والدخول، ثم طلب قسمًا يجهز بريدًا لشركات الوساطة عن الوحدات المتاحة وصورها وأسعار إيجارها. وافق المستخدم صراحةً على معاينة وتجربة الحملات فقط؛ لم يمنح تفويض إرسال حقيقي.

الصفحة العامة في `/`، ولوحة الإدارة في `/dashboard`، ومداخل الحساب `/register` و`/login`، والتجربة الصريحة بدون حساب `/demo`. الصفحة العامة لا تركب سياق مساحات المستخدم ولا تقرأ بيانات المحافظ. يتشارك HTML الأولي والواجهة المتصفحية منظر React نفسه وفهرس خدمات ثابتًا مشتقًا من تعريفات F01–F34 وحالات المرحلة الحالية. الخدمات القادمة، ومنها المستشار والقناص، تبقى مؤجلة، والتكاملات غير الفعلية لا توصف كمفعلة. الفواتير ونماذج العقود موجودة كإضافات واضحة. الصور المعمارية تصوّر توضيحي وليس دليل ملكية.

التسجيل والدخول يستخدمان Manus OAuth الحالي وجلساته الموثقة، وليس كلمات مرور جديدة أو حسابًا تجريبيًا منتحلًا. nonce والمشروع وملفات الجلسة لم تتغير، والعودة ثابتة إلى `/dashboard`. الضيف خيار صريح في نطاق محلي، وليس تفويض خادم. error التحقق لا يفتح الضيف تلقائيًا. صفحات الحساب والإدارة تبقى noindex والـsitemap يقتصر على الصفحة العامة. التقديم العام لا يغير خدمات API أو مسارات الاستحقاق أو سجلات المستخدم.

`/marketing` قسم حملات للوسطاء؛ الشركات واردة يدويًا ببيانات اختبارية، والرسالة تستعمل أهداف تأجير شاغرة وأسعار إيجار الموظف وليس قيمة أصل العقار. يجب إعادة التحقق من الشغور عند حفظ الحملة. الصور المحلية للمالك تبقى في مساحة المتصفح ولا تصبح روابط إرسال عامة، ولا تدخل مستندات الائتمان والهوية أو عقود المتقدمين في الرسائل. حالة الحملة «معاينة غير مرسلة» ولا نقد أو ذمم أو إشغال من حفظها. لا مزود إرسال ولا Trigger ولا فحص صندوق بريد ولا CSVقائمة مشتراة ولا رسائل خارجية.

تستمر الحدود الحالية للحفظ والأدوار والتزامن. يجري التحقق ببيانات مصطنعة فقط؛ لا تجربة تسجيل حساب واقعي أو إرسال بريد أو تعديل قاعدة بيانات. حفظ الإصدار وتحديث الرابط العام عمليتان منفصلتان.
