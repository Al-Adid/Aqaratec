# تصحيح خانة وصف العقار وتنظيم صفحة الإضافة

26 أكتوبر 2026 — توثيق داخلي لتحديث المعاينة فقط؛ لا نشر عام.

## تصحيح المقصود

طلب المستخدم خانة «وصف العقار» في إضافة العقار نفسها، لا تجميع الشقق والفلل في ملف الأصل بعد الحفظ ولا مربع كتابة حر. الخانة أصبحت select واحدًا في أول قسم «بيانات العقار» بخيارات شقق / فلل / وحدات ترميز، إضافة إلى غير محدد للسجلات غير المصنفة. اختيارها مستقل عن نوع الأصل؛ يمكن أن يكون نوع الأصل عمارة أو مجمع فلل، ووصفه يوضح الوحدات التي يحتويها.

يحفظ الاختيار في propertyProfile.unitComposition بإحدى القيم apartments / villas / coded_units ضمن ملف v1 المتحقق منه. النص الحر السابق بقي metadata.description ويظهر في «وصف نصي إضافي» داخل التفاصيل الإضافية. لا تستنتج قيمة للسجل القديم من النص أو الاسم أو نوع الأصل، وتعرض القيمة المحفوظة في ملف العقار وفي تعديل بياناته.

في إضافة جديدة ينقل اختيار الوصف النمط إلى تقسيم وحدات ويظهر العدد بحده القائم 2–50، وتفتح المرحلة الثانية بعد الحفظ. الاختيار في سجل موجود لا يحول نمطه أو ينشئ وحدات أخرى أو يبدل رموزها وتصنيفاتها. «شقق» و«فلل» يقترحان النوع في مسودة جديدة غير مخبأة لوحدة غير مصنفة؛ الاقتراح ليس حفظًا ضمنيًا، وترتيب الفيلا أو توزيع الشقة يبقيان بلا تخمين حتى يختارهما المستخدم ويعتمد الحفظ بمدقق الوحدة القائم. التصنيف المدخل ومسودة المستخدم لا يستبدلان بالاقتراح. «وحدات ترميز» تبقى برموزها الحالية وإمكانية تخصيص نوع لكل واحدة.

## ترتيب الصفحة

أقسام فعلية مرتبة داخل النموذج: بيانات العقار؛ الوحدات والهدف والتسعير؛ المساحات وحالة التأجير؛ الأرقام والموقع والصور والمخطط؛ ثم تفاصيل إضافية قابلة للطي. جميع الحقول السابقة بقيت متصلة بالحفظ: بنك الرهن عند مرهون، هدف بيع/إيجار/مختلط، أسعار الأصل الكامل أو بيانات سعر الوحدة المستقلة، المساحات والتأجير والتواريخ، الأرقام والموقع والمرفقات، النص والمرافق وحساب التحصيل والصيانة والملاحظات. لم تكرر الحقول ولم تحذفها لمجرد تبسيط الشكل.

CSS الجديد محصور في .property-dialog؛ الأقسام مرقمة والشبكة بعمودين على المكتب وعمود واحد تحت 760px، مع حفظ/إلغاء sticky أسفل منطقة تمرير نافذة العقار. ترتيب DOM يثبت ظهور اختيار وصف العقار في أول قسم، لا مجرد عنوان آخر في أسفل الصفحة.

## الحفظ والسلامة

يبقى حد 32 مفتاح metadata و1024 حرفًا للملف الوصفي؛ الغياب غير المحدد والقيم الثلاث المتحققة والمسح الصريح محفوظة. وصف العقار والنص الحر والمرافق حقول مستقلة، وتغيير الاختيار لا يمس مساحة أو سعرًا أو تصريح تأجير أو عقدًا أو تحصيلًا أو معرف وحدة. حراسة الدور والمحفظة ومساحة العمل وإعداد/تراجع مرفقات المتصفح والتحقق الأصلي للنموذج محفوظة. الصور كما كانت محلية IndexedDB لهذا المتصفح، ولا تنقل ضمن JSON أو السحابة. لا تغييرات قاعدة بيانات أو خدمة خارجية أو نشر.
