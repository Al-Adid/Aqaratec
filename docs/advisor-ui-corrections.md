# تصحيحات واجهة المستشار العقاري وقنّاص الفرص

**النطاق:** واجهة البروتوتايب المحلية الصورية فقط. لا يتضمن هذا العمل نشرًا عامًا، قاعدة بيانات، تفويض شراء أو تمويل، أو مسح سوق حي.

## ما تم تصحيحه

### R03 — قياس التشغيل والبيانات الناقصة

- أصبح مصدر الأرقام وتاريخ التشخيص ظاهرين في ملخص التشخيص.
- أضيفت حقول اختيارية بصيغة `YYYY-MM` لبداية ونهاية نافذة قياس التشغيل. تمرر الحقول إلى المحرك الموجود؛ لا تنشئ حسبة ثانية في الواجهة.
- تعرض الواجهة نافذة القياس الفعلية، عدد الأشهر الصفرية والمرصودة، ومدخلات المخاطر (المستوى، مدة التجميد، والوقت الشهري).
- تظهر موثوقية الدخل التشغيلي صراحة. عند محدودية أو عدم كفاية البيانات لا تسمي الواجهة دخلًا تشغيليًا مستدامًا.

### R05 — المسودات غير الصالحة لا تسقط العرض

- جميع حسابات الصفقة والتشخيص ومراجعة البناء في صفحة المستشار محاطة بنتيجة نجاح/فشل قابلة للعرض بدلاً من رمي خطأ أثناء `render`.
- مدة البناء/التسويق صفر أو كسرية، أصل دين أكبر من التكلفة، أو نسبة شغور غير صالحة تبقي القيم المدخلة قابلة للتحرير، وتعرض رسالة عربية قرب الحقل. تعرض النتيجة السابقة فقط بعلامة عدم التطابق حيث تكون موجودة.
- يعالج قناص الفرص مسودة ضغط 101% برسالة بجوار حقول الضغط ويخفي جدول المقارنة غير المطابق. لا يستخدم أي ناتج قديم أو يحفظ موجزًا من هذه المقارنة.
- بطاقات تفاصيل الفرصة لا تستدعي محرك الصفقة أو الملاءمة مباشرة داخل العرض؛ تستخدم النتائج المحروسة نفسها وتعرض الخطأ بدل انهيار الواجهة.

### R06 — نسخ الخطة والمراحل

- تستخدم الصفحة `commitTransition` مع `buildAdvisorPlanVersionTransition` الذري الموجود لحفظ ملف الخطة والمراحل وسجل سبب/تاريخ المراجعة معًا.
- تغيير أفق الخطة 1/5/10 سنوات أو الميزانية الموثقة ينشئ إصدارًا جديدًا. تبقى مراحل الإصدار السابق محفوظة ولا تتكرر مراحل الإصدار النشط عند النقر المتكرر.
- أضيف ربط `planFamilyId` إلى سجل مراجعة الإصدار، وتعرض الواجهة النسخ المؤرشفة من العائلة نفسها. تغيير نافذة قياس التشغيل كذلك يعد تغييرًا موثقًا للإصدار.

### R01 وR15 — ملاءمة الفرص وصدق المصدر

- تعرض تفاصيل الفرصة الآن النقد، التمويل المعتمد المطبق، التمويل المحتمل المشروط، العجز المؤكد (النقد والاعتماد فقط)، والعجز بعد التمويل المحتمل بشكل منفصل.
- تعرض الملاءمة الاقتصادية بحسب الهدف، المعايير المتحققة/غير المتحققة، سبب الفرز، والنواقص؛ لا تعتمد الرسالة على الدرجة وحدها.
- تعرض قائمة الفرص وتفاصيلها المصدر، تاريخ المصدر، وتاريخ التحقق. يطبع الحقل الغائب `غير مسجل` ولا يُصطنع تاريخ تحقق.
- تبقى العينات معلنة باعتبارها مراجع تجريبية ثابتة وليست مصدرًا حيًا أو عرضًا سوقيًا أو ضمان عائد.

## حدود ما بقي محاكاة

مصدر القناص fixtures ثابتة محلية، والتحقق البشري والحقوق والأهلية لا تتحول إلى اعتماد قانوني أو سوقي. يلزم مشروع إنتاج مستقل للصلاحيات الخادمية، سجل تدقيق غير قابل للتعديل المعتاد، نسخ احتياطي واسترداد، دفتر مالي مضبوط، ومصادر سوق موثوقة قبل أي استخدام إنتاجي.
