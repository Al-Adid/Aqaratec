# صُنّاع الفرص — تعليمات النسخة المصححة

تاريخ التسليم25 أكتوبر2026. الحزمة كود مصدر للبروتوتايب، بما فيه الفواتير والمستحقات وسند القبض وLPO، وقوالبالعقودTXT/Wordوتعبئتها، وتأجيرالعقاركاملًاأووحدات، وإصلاحاتالحساباتوالحفظوالاستحقاقاتوالتقاريروالاستيراد.

**ZIPليس تطبيقًا يفتح مباشرة على الآيفون.** يُفك للاطلاع أو يُسلَّم للمطور. التحديث محفوظ في الكود والمعاينة، ولم يُنشر للعامة أو يُستبدل محتوى الرابط العام. لا يعني طلب الأرشيف الموافقة على النشر.

## ما يتضمنه

المجلد`sunnaa-furs-prototype`يتضمن الواجهة`client`والخادم`server`والقواعدالمشتركة`shared`والمخططوالهجراتالقائمة`drizzle`والاختباراتوالقفل وDockerfileوالخطة وقائمةالإنجاز. ملفات`docs/qa-evidence`توثق الأدلةقبل/بعد ونتائجالفحص. مجلد`delivery`يضم تقرير الإصلاحات وخطةالإنتاج وهذهالتعليمات. ملف`EXPORT_INFO.json`يعطيSHAلنسخةGitوحدودالتسليم.

لايتضمن`.git`أو`node_modules`أو`.env`أومفاتيحأونسخةقاعدةبياناتأوبياناتمتصفحك. بياناتالتجربةالصوريةالمكتوبةبالكودفقطمرفقة. المصدرلايعنيإمكانإعادةخدماتManusأوصورهاخارجبيئتهادونإعداد.

## التشغيل على الكمبيوتر

يلزمNode.js22 وpnpm10.18.0. داخل المجلد بعد فك الضغط:

```bash
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

افتح`http://localhost:3000`على الكمبيوتر الذي يشغلالخادم، وليس رابطًا عامًا للآيفون. الخادم يستعملPORTأو3000. لا تشغل`dev`و`start`معًا على المنفذ نفسه.

```bash
pnpm check
pnpm test
pnpm build
pnpm start
```

`pnpm dev:static`معاينةواجهةفقط. مع غيابbackendصحيحتبقىهويةالحسابغيرمتحققةوقدتُقفلعملياتالإضافة؛ لاتعتبرهذاالوضعبديلًاتفاعليًاكاملًا. لتجربةالحفظالمحلييلزمتشغيلالخادمووصولauth.meالصحيح؛ الدخولوالسحابةوالذكاءالاصطناعيوتخزينManusتحتاجتهيئةخدماتهاولا تُرفَقأسرارهافيالحزمة.

## الحفظ والاسترداد

الحفظ المحلي مقسم حسب الحساب ومساحة العمل. في حال ملفتالف أو نسخةقديمةغيرمنسوبة يظهر **تنبيهالحفظوالاسترداد** بكلصفحة. افتحخياراتهلتصديرالأصلأوإصلاحصريحأومساحةمنفصلة؛ لايفترضأنقراءةالديموبديلللبياناتالقديمة. معquotaقدتبقىالتغييراتفيالذاكرةفقط؛صدّرهاقبلإغلاقالصفحة. لا تعتمدالمتصفحنسخةاحتياطيةمالية.

السحابة لقطة بروتوتايب خاصة للحساب وليست منظومة مؤسسة/فريق أو دفترمحاسبي. تعارضCASلايستبدلبياناتجهازآخرصامتًا.لاتشغلهجراتعلىقاعدةقائمةأوتستبدلبياناتقديمةدونمراجعةونسخاحتياطي.
