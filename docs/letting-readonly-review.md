# مراجعة رحلة وحدات غير مؤجرة — نتيجة المعالجة

أُجريت مراجعة مستقلة للقراءة فقط، ثم عولجت العيوب الثلاثة التي أثبتتها دون تشغيل بريد أو تقويم خارجي أو تغيير بيانات مستخدم.

## التصحيحات المثبتة

1. **دعوة الموعد:** رُبط `downloadLettingCalendarInvite` بزر «تنزيل دعوة الموعد ICS» في نافذة الموعد. اختبار واجهة فعلي يثبت استدعاء المساعد بالطلب والفتحة المحجوزة نفسيهما، مع عبارة «تنزيل محلي فقط؛ لا إرسال دعوة ولا مزامنة».
2. **تاريخ التسليم:** يرفض المحرك إقرار المستأجر وتأكيد استلام الأصول المستقبليين بالنسبة لساعة السيناريو. يظل حجز موعد مستقبلي ممكنًا. `activateLease` يستعمل تاريخ استلام الأصول المؤكد لا تاريخ اليوم المعروض. يثبت اختبار الرحلة الرفض وعدم إنشاء أثر جزئي وتطابق `activatedAt` مع الاستلام، حتى إذا أكمل الموظف الإدخال في اليوم التالي.
3. **حجم الملفات:** حد موحد `LETTING_ATTACHMENT_MAX_BYTES` يساوي خمسة ميغابايت لكل ملف تأجير. تعرضه الواجهة وترفض التجاوز قبل التحقق والتخزين، ويستعمله المحرك. لم تتغير حدود مرفقات العقار العامة.
4. **بيانات العقد:** استُكملت اللقطة المحفوظة باسم الطرف وبيانات الشركة والسجل والقيد والمفوّض والهوية المدخلة والتواصل والعنوان والموقع ونوع العقار ورقم الكهرباء والمدة والتواريخ والإيجار؛ يتحقق اختبار التكامل من ظهور هذه البيانات داخل الوثيقة، لا في ملف المتقدم فقط.

## الأدلة

- المجموعة الكاملة قبل هذه التصحيحات: 70 ملفًا، 322 اختبارًا ناجحًا وواحد سابق متروك معلن.
- بعد التصحيحات: 21 اختبارًا مركزًا ناجحًا في خمسة ملفات، تشمل الأفراد والشركات وعمارة من تسع وحدات وزر الدعوة ورفض الملف الزائد والإقرار المستقبلي وتفعيل العقد واستلام الشيكات دون نقد.
- أعيد تشغيل الفحص الشامل والأنواع والبناء قبل الحفظ؛ نتائجه النهائية في `docs/letting-validation.md`.

## حدود معلنة

البريد `suhaim@qissatec.com` عنوان تجريبي؛ كل الرسائل معاينات غير مرسلة. الملفات محلية في IndexedDB ومعزولة بمساحة العمل، ولا تنتقل بايتاتها مع لقطة JSON السحابية. لا OCR أو تحقق رسمي من الهوية أو مكتب الائتمان؛ يدخل الموظف بيانات تقرير اختباري ويراجع مصدره، ثم يقرر وفق سياسة سعر ودرجة محددة. تمثيل المستأجر داخل التجربة ليس بوابة خارجية موثقة. دعوة ICS تنزيل اختياري وليست حجزًا في تقويم الموظف الحقيقي. العقد نص تجريبي يتطلب تدقيقًا قانونيًا وبشريًا مستقلًا. لم تُختبر رسائل أو ملفات عملاء حقيقية، ولم تعدّل قاعدة الإنتاج.
