# محتويات العقار: شقق وفلل ووحدات مرمّزة

26 أكتوبر 2026 — توثيق داخلي لتحديث نسخة المعاينة، دون نشر عام.

## التجربة

ملف العقار المقسم يعرض «محتويات العقار — تقسيم الوحدات» مع أعداد الشقق والفلل والمحلات والمكاتب والوحدات الأخرى وغير المصنفة. يمكن النقر على النوع أو اختياره في «تصنيف الوحدات المعروضة» لتصفية جدول الوحدات، مع بقاء بقية وحدات الأصل محفوظة. مصدر العدد هو unitProfile.category للوحدات المادية التابعة للعقار والمحفظة، بعد استبعاد هدف العقار الكامل الداخلي والتكرار. لا ينشأ عدد وحدات جديد من التجميع ولا يخمن نوع من اسم الأصل أو نص محتويات الغرف.

في المرحلة الثانية يظهر «نوع الوحدة» و«رمز الوحدة» إلى جانب الاسم والبيانات السابقة. الرمز الحالي U-01 ونحوه يبقى إذا لم يعدله المستخدم، وأمثلة A-01 وV-01 اختيارية وليست بادئات إلزامية أو أرقامًا حكومية. يمكن حفظ أرقام عربية وأصفار بادئة، وتمنع القاعدة القائمة تكرار الرمز داخل الأصل بعد تطبيع الأرقام وحالة الأحرف، دون حفظ جزئي أو تغيير معرف الوحدة أو مراجع العقود التاريخية.

قواعد الوصف القائمة محفوظة: الفيلا تحتاج اختيار ترتيب متلاصقة/منفصلة، والشقة تحتاج توزيعًا صحيحًا وأعداد غرف وصالات متوافقة. الواجهة لا تختار استوديو أو فيلا منفصلة بمجرد اختيار النوع. عند اختيار المستخدم توزيعًا قياسيًا للشقة تطبق أعداده المعلنة، والتوزيع المخصص يبقي الأعداد الحالية قابلة للتحرير. تغيير النوع يمسح النوع الفرعي غير المتوافق فقط ولا يعيد الترميز أو يمحو باقي المواصفات.

عنوان المحتويات الحرة للأصل أصبح «مواصفات ومرافق العقار» لتفريقه عن تقسيم الوحدات. البيانات السابقة وقائمة الخيارات المحفوظة ومحتويات الوحدة ووصفها ومساحتها وتسعيرها وتأجيرها وصورها تبقى مستقلة دون ترحيل أو تحويل نص الغرف إلى وحدات.

## السلامة

التحديث يحفظ الحقول المعدلة فقط عبر updateDescribedUnit؛ يبقى النوع أو الرمز الأحدث الذي لم يعدله المستخدم محفوظًا عند تحرير حقل آخر. الحراسة القائمة للموظف والمحفظة ومساحة العمل وسعة الميتاداتا قائمة. لا يوجد تعديل لعقد أو ذمة أو قبض أو إشغال مالي أو علاقة محفظة بسبب التصنيف والترميز. الصور محلية IndexedDB كما كانت، والحفظ المحلي وJSON/السحابي الاختياري الحالي كما هو دون مزامنة جديدة.

المراجعة المستقلة لم تجد عائقًا جديدًا مثبتًا. الملف الوصفي المشوه يرفضه المحرك الحالي ذريًا؛ لم تضاف آلية تخمين أو تسامح أو ترحيل خارج نطاق الطلب. تغيير unit-profile.ts ضمن هذه النسخة تنسيق للرسائل فقط دون تعديل قواعد التحقق.
