# عروض البيع ضمن حملات الوسطاء — 28 أكتوبر 2026

## النتيجة الوظيفية

أصبحت عروض البيع والإيجار في جدول أهداف التسويق نفسه: البحث والنوع وهدف التسويق والتحديد الفردي وتحديد كل النتائج المعروضة، ثم اختيار شركات الوساطة وتجهيز الموجز. أزيل مسار البيع المنفصل للقراءة من صفحة الحملات؛ قسم «وحدات للبيع» المستقل وقارئ مخزون البيع لم يتغيرا.

أهداف البيع تقرأ من مخزون البيع ضمن المحفظة الحالية. الأصل الكامل يمثل هدفًا واحدًا دون وحدة مادية وهمية، والوحدات المادية المعروضة للبيع تمثل أهدافها الخاصة دون عرض أصل مكرر معها. يظهر العرض المؤجر للبيع مع حالة التأجير الفعلية ولا يتحول إلى شاغر للإيجار. لا تستخدم تواريخ توافر الإيجار كوعود تسليم للبيع.

## الأسعار واللقطات

سعر البيع مستقل عن الإيجار الشهري. سعر الوحدة من ملفها فقط دون إيجار أو تكلفة أو سعر أصل مخفي بديل. السعر المفقود يبقى مفقودًا ويحتاج المستخدم إلى مبلغ موجب صريح قبل تجهيز الموجز. التعديل داخل الحملة لا يعدل سعر العقار أو الوحدة.

لقطات البيع تحفظ `purpose: sale` و`salePriceMinor` موجبًا، مع `monthlyRentMinor: 0` لأسباب توافق شكل السجل فقط، لا كقيمة إيجار. اللقطات التاريخية دون غرض تبقى إيجارًا. الحملات المباشرة المختلطة ترفض وتوجه المستخدم إلى إعداد الدفعات؛ إعداد الدفعات يفصل البيع والإيجار وتسمياتهما ولا يجمع سعر بيع مع إيجار شهري.

وجدت المراجعة المستقلة خطر إعادة استعمال مسودة سعر بين الهدفين عند تغيير غرض وحدة مع بقاء معرفها. عولج بمفتاح مسودة يشمل الغرض ومعرف الهدف، ومسح المسودات وإلغاء التحديد والتجهيز عند تغير الغرض أو علاقة المحفظة/العقار. ثبتت الحالتان: إيجار إلى بيع وبيع إلى إيجار، ضمن إعادة فحص الصفحة.

## الصلاحيات وعدم تغيير الماليات

إعداد الحملة والمحاكاة يعيدان التحقق من الهدف الحالي والمحفظة والوسطاء والنشاط والسعة والتكرار. ضوابط القراءة تمنع التحديد وتعديل السعر والتجهيز وتأكيد المحاكاة. عمليات التسويق تقتصر على سجلات الحملة/المحاكاة والتدقيق، وسجل الوسيط عند تعديله، ولا تنشئ أو تعدل عقودًا أو وحدات أو ذممًا أو تحصيلًا أو قيودًا أو إيراد بيع.

## حدود البريد والمرفقات

TXT وEML وmailto تحمل موجز البيع وتسميته وسعره وحالة التأجير. EML مسودة غير مرسلة لمستلم واحد وmailto يفتح تطبيق بريد المستخدم للمراجعة والإرسال اليدوي. تأكيد الإرسال داخل النموذج محاكاة محلية فقط؛ لم يضف مزود بريد أو SMTP. الصور والمخططات والفيديوهات المحلية لا تدخل نص الموجز أو مرفقاته تلقائيًا، ولا يتضمن ZIP بيانات المتصفح أو قاعدة البيانات الحية أو الأسرار.
